Manual Setup Instructions
Step 1: System ID Check करें

सबसे पहले Systems page पर जाएं और अपने PC का ID note करें।

Step 2: Client PC पर Setup करें
Windows: 
pip install psutil requests
python monitoring_agent.py --system-id YOUR_ID --server http://YOUR_SERVER_IP:5000
Linux/Mac: 
pip install psutil requests
python monitoring_agent.py --system-id YOUR_ID --server http://YOUR_SERVER_IP:5000
Step 3: Verify Connection

Agent run करने के बाद Systems page पर वापस आएं और status check करें।

Network Requirements
  • ✅ सभी PCs same network में होने चाहिए
  • ✅ Port 5000 accessible होना चाहिए
  • ✅ Python 3.6+ installed होना चाहिए
  • ✅ Internet connection (dependencies install करने के लिए)
